Цифровой помощник колледжа

О проекте
Цифровой помощник колледжа — веб-приложение, предназначенное для автоматизации взаимодействия студентов и сотрудников колледжа с администрацией, упрощения процесса подачи обращений и предоставления информации об учебном заведении с помощью искусственного интеллекта.

Система объединяет ИИ-помощника, электронную систему обращений и административную панель для управления заявками и информационными материалами.

Основные возможности
1. ИИ-помощник
Ответы на вопросы пользователей, связанные с колледжем.
Использование Groq API для обработки запросов.
Работа с базой знаний колледжа.
Предоставление информации по заранее подготовленным материалам.
Передача сложных или нестандартных вопросов администратору, если ИИ не может предоставить подходящий ответ.
2. Система обращений
Создание нового обращения.
Указание темы и описания проблемы.
Выбор категории обращения.
Указание местоположения, связанного с проблемой.
Получение информации о созданном обращении.
Отслеживание состояния обращения.
Просмотр актуального статуса заявки.
3. Панель администратора
Административная панель предназначена для централизованного управления обращениями и информационными разделами системы.
Возможности администратора:
Просмотр общей статистики.
Просмотр всех обращений.
Просмотр новых обращений.
Работа с обращениями, находящимися в обработке.
Изменение статусов обращений.
Просмотр распределения обращений по категориям.
Управление категориями и местоположениями, если соответствующие функции предусмотрены интерфейсом.
Управление QR-кодами.
Управление базой знаний ИИ.
Просмотр подробной информации по отдельным обращениям.
4. QR-коды
QR-коды позволяют быстро перейти к соответствующей странице системы, в том числе к созданию обращения, без необходимости вручную вводить адрес сайта.
5. База знаний ИИ
База знаний содержит информационные материалы, используемые ИИ-помощником при формировании ответов.
Администратор может управлять информацией, чтобы поддерживать актуальность ответов системы.
Используемые технологии

Структура проекта
Основные элементы проекта:
app.py — основной файл приложения Flask.
templates/ — HTML-шаблоны страниц.
static/css/ — таблицы стилей.
static/js/ — JavaScript-файлы.
requirements.txt — список необходимых Python-библиотек.
knoledge_base.py — модуль базы знаний (название файла указано в соответствии с текущей структурой проекта).
.env — файл с конфиденциальными настройками и API-ключами.
*.db — файлы баз данных SQLite.
README.md — документация проекта.

Установка и запуск
1. Подготовка
Для запуска проекта необходимо установить Python.
Рекомендуется использовать Python 3.10 или более новую версию, совместимую с зависимостями проекта.
2. Открытие папки проекта
Откройте терминал в корневой папке проекта, где находится файл app.py.
3. Создание виртуального окружения
python -m venv venv
Активация в Windows:
venv\Scripts\activate
4. Установка зависимостей
pip install -r requirements.txt
5. Настройка переменных окружения
В корневой папке проекта создайте файл .env.
В нём укажите API-ключ Groq в соответствии с названием переменной, используемым в app.py.
Пример оформления:
GROQ_API_KEY=ваш_api_ключ
Важно: название переменной должно совпадать с тем, которое используется в исходном коде приложения.
API-ключ необходимо хранить в конфиденциальном виде. Не публикуйте его в открытых репозиториях и не включайте настоящий .env в архивы, предназначенные для передачи другим пользователям.
6. Запуск приложения
Запустите приложение командой:
python app.py
После успешного запуска откройте локальный адрес, указанный Flask в терминале.
База данных
В проекте используется SQLite для хранения информации приложения.
База данных обеспечивает работу с обращениями и другими данными, необходимыми для функционирования системы.
Файлы баз данных имеют расширение .db.
При переносе проекта необходимо учитывать, какая база данных используется приложением в текущей конфигурации.
Безопасность
API-ключи хранятся в файле .env.
Конфиденциальные данные не должны публиковаться в открытом доступе.
Для передачи проекта следует использовать .env.example без настоящих ключей.
Доступ к административной панели должен быть защищён авторизацией.
Пароли администратора рекомендуется хранить в виде криптографических хешей, а не в открытом виде.

Назначение проекта
Проект разработан для цифровизации процессов взаимодействия студентов и сотрудников колледжа с администрацией.

Его основная цель — сделать подачу обращений более удобной, ускорить получение ответов на типовые вопросы и упростить обработку заявок административным персоналом.
